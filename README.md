# Real-Time Auction Platform

A full-stack real-time auction platform built using the MERN stack with live bidding functionality, image uploads, category filtering, search, dashboard analytics, and responsive modern UI.

---

## Features

- User Registration & Login
- Create Auctions
- Real-Time Bidding
- Live Countdown Timer
- Bid History
- Highest Bidder Display
- Search Auctions
- Category Filtering
- Dashboard Analytics
- Image Upload Support
- Responsive Modern UI
- MongoDB Database Integration
- Cloudinary Image Hosting
- Socket.io Real-Time Updates

---

## Tech Stack
